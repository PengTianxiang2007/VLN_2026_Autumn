## 退出机制

开发Precision≥85%且Recall≥80%进入验证；连续三轮最佳F1未提升至少2个百分点退出；修改最多六轮；模型就绪后总运行最多八小时，并为验证预留时间。请求最多重试一次，仍失败或服务/资源异常即退出并记录阻塞。停止调参后冻结最佳版本，验证集只用于最终报告，不用于继续调参。正常或异常收尾均清理本次服务。

两轮修改均来自完整开发结果和对应RGB/原始回答：r01针对“直行＋侧门也可构成选择点”的定义漏判；r02针对先生成status、随后描述两条通路却仍判否的输出矛盾，改为先列通路再判状态。单帧探针只验证改动能改变该帧回答，不作为轨迹成绩。
