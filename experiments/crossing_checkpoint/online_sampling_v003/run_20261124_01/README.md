# 用局部 JEV 信号筛选候选代表点

目标：尽量提高覆盖，在采纳率 60%、70% 两档分别报告代价。同时保留既有全覆盖对照。沿用 v002 的随机划分（种子 20261124）及 11 条排除清单，轨迹 seed 2，容差 ±3 步。22 条验证集已有 v002 历史结果，本轮只在 20 条上设计，不新增标签，不用验证集调参。工作区基线 e40d9a821ee72516261ee819284e36be7be2eff1，既有 v002 及索引等未提交修改保留。

从 v001 原始候选周围选择代表位置，用当前已到达的 JEV 分数、滤波值和候选历史估计邻域内有参考点的可能性。保留原窗口与总延迟 5 步，不读取几何、RGB、任务、ID、轨迹长度或结束信号。设计阶段按场景留一拟合正则化线性模型，在场景外预测上选阈值；报告匹配数 / 候选数和匹配数 / 参考数。优先有覆盖的方案，不用极少几个高分点凑比例。冻结配置和源码摘要后整批验证一次；旧验证集只能提供复用留出集上的结果。CPU 离线实验。

## 实现与冻结

每个 v001 原始候选 q 提议位置 q+2。到达 q+7 时读取已确认的平滑值、局部变化、原始候选间距和触发状态，使用 11 个数值特征的岭正则 logistic 模型打分。间隔和阈值控制是否发出。窗口末端不足 5 步不补发。设计中对同场景整组留出，线性模型固定惩罚系数 5，只扫描 7 / 10 步最小间隔及 0.05 粒度的阈值。将至少 12 个匹配、6 条命中轨迹作为候选工作点的支持下限。20 条设计轨迹包含 15 个不同场景。最终权重在全部设计轨迹拟合。

第一阶段锁定 F1 最优及 60%、70% 目标设置；F1 与 60% 档重合。第二阶段在打开该轮 22 条验证前，从同一设计网格补入覆盖至少 75% 时采纳率最高、以及支持数达标时采纳率最高的设置。所有四档一次性冻结后，在同一批复用的留出轨迹上统一验证一次。场景外结果参与阈值选择，因此仅作设计证据。
