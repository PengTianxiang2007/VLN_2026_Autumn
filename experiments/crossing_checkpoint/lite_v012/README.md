# lite_v012：受限侧面默认保留为可能

2026-11-08 UTC。状态：目标集与控制面板完成，达到本轮有效性门槛。

`lite_v011` 将 F58 从1分提高到2分，但F96、F105仍为1分。本版在v011后追加一个通用默认原则：受限侧面只要没有被完整、连续的封闭结构正面排除，就优先标记为“可能”；可见门框、墙端、凹口、柜体端部或遮挡边缘留下的未分类空间和地板延续都保留为候选。

不添加样本名称、方向特例或固定分数，仍使用原输入、模型、参数和JSON schema。

结果：

- 目标三帧：F58由1升至2，F96由1升至3，F105仍为1；
- 47个人工标注帧中，分数 `>=3` 从25增至30；
- 20个远离标注且两旧版均为1分的稳定性控制帧中，17个仍为1、3个升至2、0个达到3以上；
- 人工标注帧有13个升分、19个降分，降分主要是5分变为3分；在 `>=3` 阈值下净增5个。

结论：候选可能路线规则产生了可测效果，且控制帧没有普遍升到多路线分数；但人工标注帧仍有降分和无标注帧不能作为真正负类，不能宣称准确率提升。停止继续针对F105调参，后续应做冻结后的更大范围验证。
