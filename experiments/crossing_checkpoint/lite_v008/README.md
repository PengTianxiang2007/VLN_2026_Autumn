# lite_v008：重写局部路线判定流程

2026-11-08 UTC。状态：草稿，尚未运行。

本版不再在 `best_v001` 上追加局部补丁，而是重新组织完整 prompt。保留原来的三帧输入、局部路线选择定义、10步范围、来路规则、1—5分和JSON输出；核心变化是：

- 先建立当前局部空间，再将每个方向的入口分类为“确认路线”“可能路线”“排除”；
- “无法看清”不等于“明确排除”；
- 画面边界、墙端、门框、柜体或遮挡物之后，只要存在具体空间延续线索，就保留为可能路线；
- 1分要求所有方向都被明确封闭结构正面解释，而不是仅因当前帧看似单一路线；
- 可能路线根据证据强度落入2—4分，不提前跳过中间分。
