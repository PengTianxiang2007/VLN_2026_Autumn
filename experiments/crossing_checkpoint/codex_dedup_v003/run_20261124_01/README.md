模型沿用 gpt-6-astra / medium，9 个进程，每例独立新会话。先单独发送已确认的方法初始化英文译文，再逐候选续聊。每组图像只在该候选出现时发送一次，使用完整候选 ID 及图像标签关联历史。每轮明确指定上一保留节点，先判断多条支路能否通往不同空间区域，再判断是否与历史回退点重复或出现不同/新增支路。视野受限时允许依据可见空间结构推断。
