## 目的与版本

用户要求验证当前 GPU 0 共享资源下，能否部署已有 Qwen3.8-27B-FP8，供后续 Crossing 方法迭代使用。

## 设置与停止条件

- 当前 GPU 0 约 43531 MiB 可用，既有他人进程保持运行。启动前连续两次低负载检查。
- 同一 FP8 权重与 vLLM 0.19.1；单卡 TP=1、并发=1、显存比例 0.80、32K 上下文、CPU offload=0。
- 原 v001 开发轨迹 `kujiale_0036_10_0` 中，具有完整八帧上下文的首个、中间、最后一个观测，共三个串行请求。
- 每个请求保持八张 640×480 纯 RGB、动作历史、原历史语义记忆、原逐请求 seed、temperature=0、关闭思考、max_tokens=8192。
- 重建请求必须与 v001 请求 SHA256 一致。结果只验证加载、请求完成、schema 和资源开销，不评估方法准确率或单/双卡输出等价性。
- 模型就绪最多等待 2700 秒；每请求最多 600 秒。任何异常结束测试；正常或异常均逐 PID 清理本次服务并核验 GPU。
