# C32 v006.1 双模型 Fast 同时重跑

目的为比较 GPT-6 Astra 和 GPT-6.1 Terra 的端到端耗时。使用同一份 C32 清单与 v006.1，seed 2、8 个原始候选，前视 F-2/F0/F+2，medium、priority、17982。每组独立新会话，分别初始化和顺序评审 8 次。两组同时启动；整例取各自 status.json 的起止时间，调用取 response.json 的 elapsed_seconds。命令见 launch.json。
