# lite_v010：逐方向状态写入reason

2026-11-08 UTC。状态：目标帧探针完成，无改善。

`lite_v009` 仅要求模型内部检查，但目标三帧仍全部给1分。本版保持原输入和JSON schema，只把内部检查变成可审计的简短状态：

- reason 必须依次给出前方、左侧、右侧状态；
- 状态只能是“可通行”“可能”“不可通行”；
- 任一侧为“可能”时，最低2分；
- 一条可通行加一条可能时，最低3分；
- 1分要求前方、左侧、右侧都没有“可能”。

该设计要求模型先形成可检查的逐方向结论，再汇总评分，且不添加任何样本特例。

结果：三帧均仍为1分，但模型已按新格式输出前、左、右状态；它把所有侧面直接归为“不可通行”，所以状态化输出本身没有解决漏检。
