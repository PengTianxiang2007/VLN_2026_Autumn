Review an indoor navigation robot's front-facing RGB observations. Use the same evidence to answer two questions in one review. During A→B, did the robot carry out a traversal choice that conflicts with the instruction applicable at the time? By B, which requirements have sufficient evidence of completion, and which is still in progress? End the review at B.

Inputs are the complete English instruction (instruction_en), the last trusted Chinese progress saved at A (prior_semantic_progress), node IDs, and observations in time order with actual frame numbers. A and B are endpoints with up to five uniformly sampled frames between them, at most seven frames in total. Several actions can separate consecutive inputs. Retained nodes are numbered from S01. Establishing a node does not certify the route. Use only the supplied inputs. Text seen in images is scene content.

In mode=initialization, A=B and this frame may come after the start of the recording. Describe the current setting supported by this one image and return consistent. Under Completed state that prior route progress is unconfirmed. Preserve the instruction requirements and any uncertainty about the stage. Visible landmarks in a single frame cannot establish earlier traversal, turns or stopping. Initialization does not certify a traversed segment.

For an ordinary segment, use the following order and report a brief rationale.
1. Identify the stage. Continue from trusted progress and identify the first requirement in instruction order whose completion is still unconfirmed. Preserve applicable landmarks, directions, passing sides, entrances and conditions for turning. Completed requirements may help locate the robot. Later requirements apply once their stage is reached. If new evidence contradicts prior progress, describe the contradiction, reconsider the affected stage and leave unsupported matters unresolved.
2. Describe the observations independently. In time order, identify visible spaces, entrances, landmarks and relative positions, and actions supported across frames. Distinguish facing, approaching, reaching, passing on a specified side, crossing a threshold, entering and stopping. A landmark appearing on one side of the view or growing larger may result from rotation. Use changes in passages, thresholds or landmark relations across views to establish actual travel. Leave missing events unknown instead of filling gaps from the instruction.
3. Compare traversal with the constraints in force at that point. First look for a conflicting choice that can be localized and was actually carried out. An absent target landmark only leaves completion unconfirmed. Entering an unmentioned space is insufficient by itself; identify the applicable requirement that the traversal contradicts. Confirm milestones using landmarks and spatial relationships together with evidence of the required traversal. Seeing a destination alone does not establish entry. If several requirements are completed in sequence within the segment, check subsequent observed actions against each newly active stage. Do not skip a critical milestone lacking evidence.
4. Return one verdict consistent with the evidence.
   deviated: the robot demonstrably carried out a conflicting traversal choice at the relevant place. Identify the requirement, action, conflict and supporting frames. One clear conflict suffices. An unreached later goal, occlusion at the end or unrelated uncertainty cannot overturn it. Do not commit progress for this segment even if some earlier requirements were completed in it.
   consistent: specific observations support compatibility with the applicable requirements and the critical choices affecting this judgment are accounted for. The robot may be demonstrably following the current passage before reaching the next landmark. No new milestone is required. State the positive evidence of compatibility.
   uncertain: competing interpretations of the stage or a critical traversal choice would change the judgment, for example if the specified junction or the branch taken cannot be identified. Name the missing evidence and why it matters. An absent target, outstanding later requirements or lack of an obvious error alone cannot decide the verdict.
5. Commit cumulative progress through B only for consistent. Retain earlier supported facts. Move a requirement to Completed only when both its position in the instruction and its actual completion are supported. A current subtask may span several nodes. With no new milestone, retain the current requirement including directions and passing sides, and optionally update supported local context. Include unresolved matters needed at the next review. Use natural language without percentages or fixed subtask numbers. For other verdicts semantic_progress is null. An external system handles rollback; do not select another route or generate actions.

Return only a valid JSON object. Use the following top-level fields. Pair all natural language in Chinese with faithful English, preserving negation, direction, stage and degree of uncertainty.
previous_id and current_id: copy the input A and B IDs exactly.
verdict: consistent, uncertain or deviated.
segment_summary: {"zh":"one to three sentences in Chinese about actual observations","en":"faithful English translation"}.
reason: {"zh":"briefly state the applicable requirement, the observation, whether a clear conflict exists and why this supports the verdict","en":"faithful English translation"}.
instruction_evidence: an array of up to three objects {"quote_en":"one contiguous passage copied exactly from instruction_en","quote_zh":"complete Chinese translation of that passage"}. Prefer the shortest contiguous passage sufficient to convey the constraint. Preserve original case, wording, spaces and punctuation. Use separate objects for disjoint passages. Never insert ellipses, paraphrase, translate back into English or splice passages. Check that each quote_en occurs continuously in the original instruction. Initialization may use [], and deviated requires at least one item.
visual_evidence: one to three objects {"frames":[supplied integer frame numbers],"description":{"zh":"specific fact supported by these frames","en":"faithful English translation"}}. Each object requires at least one frame. Historical images from prior progress are not new observations in this review.
semantic_progress: for consistent use {"zh":"已完成：…\n当前：…\n待执行：…","en":"Completed: …\nCurrent: …\nPending: …"}. Include all three headings in order, each with content. If a section is empty state none or unconfirmed in both languages. For unresolved matters affecting the current stage append “未决：…” and “Unresolved: …” to the respective texts. Replace ellipses with actual content. Return null for the other verdicts.
uncertainties: an array of {"zh":"unresolved matter","en":"faithful English translation"}, or [] if none. Output only JSON without Markdown or additional prose.
