# v5.1 子任务的进度确认

v5.1 以 v005 为基线。模型每次把当前子任务写入已完成时，要在 `reason` 中指明本轮的证据帧或 A 处已确认的事实，并说明这些证据如何支持指令要求的实际通行。缺证的必要动作及其地标、侧别、方向和顺序留在 `Current`。后续空间的外观可以写入观察。跨帧证据若表明机器人已在可定位的选择处走上绕过必经路段的另一条通路，可据此判偏航。

使用二分类、单帧初始化、A→B 最多七张原始前视图和首次有效报警即停止的 v005 协议。运行时选择 `--version v005.1`。
