本版从实际通行出发。模型先独立描述 A→B 确实发生的动作，再用当时生效的子任务判断这个动作是否构成路线冲突。随后按另一个问题写进度，即该子任务是否已有证据确认完成。[实际中文 Prompt](prompt_zh.txt) · [英文对照](prompt_en.txt)

## 从原答定位错误

**C35 的进度在 S02 就提前推进。** 模型只写出沿走廊前进了“部分路段”，随即把它列入已完成，下一项开始审“在走廊尽头左转”。S03 又把浅色竖条隔断认作指令中的绿色装饰板。前视 F0 可见带立体装饰的绿色板，F13 可见的是带竖纹的浅色墙面和陶罐。到 S04，模型已能描述圆形装饰位于床侧墙面，却据此确认了走廊尽头的转弯。F22 能看到装饰在床头上方，F30 能看到浴室门直接邻接床铺。S05 的原答明确写出从卧室进入浴室，但这轮收到的进度已经只剩进浴室和停靠要求。离线归因在 F37 确认选错浴室。五轮原答均通过格式校验。[C35 逐轮原答和传入进度](../../../outputs/deviation_progress/v006/run_20261120_01_qwen_gpu3_c35_c38/run/cases/C35/result.json) · [F13 输入](../../../outputs/offline_route_dataset/v001/run_20261118_01/dataset/observations/kujiale_0234_23_1/000013/policy_front.png) · [F22 输入](../../../outputs/offline_route_dataset/v001/run_20261118_01/dataset/observations/kujiale_0234_23_1/000022/policy_front.png) · [离线归因](../../../outputs/offline_route_dataset/v001/run_20261118_01/dataset/evaluation/episodes/kujiale_0234_23_1.json)

**C38 的报警理由与模型自己的观察不相符。** S02（F0→F5）收到的当前要求是右转进走廊，盆栽和厨房列在后续步骤。模型描述主要是视角转动，仍能看见门洞，理由却用“还没进走廊、没看到盆栽或厨房”得出偏航。从该回答给出的观察中找不到已经选择的冲突通路。首次报警让该轨迹在 F5 停审。离线标注的错误分支在 F72–F75，侧视图有助于事后辨认两条通路。该侧视图不属于评审模型的输入。[S02 输入进度与六帧清单](../../../outputs/deviation_progress/v006/run_20261120_01_qwen_gpu3_c35_c38/run/cases/C38/S02.request.json) · [S02 报警原答](../../../outputs/deviation_progress/v006/run_20261120_01_qwen_gpu3_c35_c38/run/cases/C38/S02.response.json) · [离线多视角归因](../../../outputs/offline_route_dataset/v001/run_20261118_01/dataset/evaluation/episodes/kujiale_0234_34_4.json)

**C38 的早期版本还暴露了另一种错误。** v5.1 在 S05 保留了尚未证实的走廊通行要求，S06 的请求也带入了它们，原答随后只凭进卧室、到床边就宣布路线全部完成。单纯提高报警门槛无法解决这类进度丢失。这两条诊断轨迹来自同一场景，离线归因为事后审阅，尚无人类一致性标注。[v005、v5.1 逐轮对照](../v005.1/run_20261120_01_qwen_gpu3_c38/README.md)

## v6.1 判断规则

| 问题 | 处理方式 |
| --- | --- |
| 本段是否有已经发生的路线冲突？ | `reason` 指出当时适用的要求、在 `segment_summary` 和 `visual_evidence` 中有依据的实际行为，以及两者如何冲突。到达可辨认的路口后选错或实际绕过必经路段，足以报 `deviated`。 |
| 当前步骤尚未完成、还在转头或抽帧遗漏时怎样判？ | 现有证据只支持这些事实时给 `consistent`，原要求留在 `Current`。后续地标只在对应阶段生效。 |
| 什么可以推进进度？ | 用来路、所在环境、侧别和实际通行辨认指令所指的地标。已证实按要求走完的子任务才能进入 `Completed`。部分执行写在 `Current`。历史进度与新观察相冲突时，恢复最早仍缺证的要求。 |

沿用单帧初始化、去重后的有效节点、A→B 端点与最多五张中间前视图、一次 VLM 调用和九字段二分类协议。`consistent` 时 B 成为下一轮 A。`deviated` 时本轮进度为 null，记录 A 为回退目标并结束该条评审。新增约束写在 Prompt 中，校验器继续负责 JSON、引文、帧号和进度格式。

中英文 Prompt 载入和二分类格式校验已在 CPU 上检查。GPU 3 Qwen 两例复评共 10 轮。C35 在 F14 报警，具体穿越隔断的理由证据不足。C38 的 F5 误报消失，模型在 S05 提前提交走廊地标进度，最终漏报 F72–F75 错误分支。[v6.1 实际结果与原答](run_20261120_01_qwen_gpu3_c35_c38/README.md) · [双版本全样本准备记录](paired53_20261120_01/README.md)
