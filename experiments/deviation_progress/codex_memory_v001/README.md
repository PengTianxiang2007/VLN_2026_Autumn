# Codex 同会话偏航识别 v001

每个 case 建立独立会话。v006.1 回退点筛选继续接收原始候选的三张前视图。每当保留或替换节点 B，在同一会话内立即追加一轮纯文本偏航评审。A 是更新后有效节点清单里 B 的前一个节点。首次只有 B 或替换后仍只剩一个节点时，以 A=B 和单帧重新初始化。每轮明确提供完整英文指令、A 的中文累计进度和允许引用的历史图像标识。被删除候选的图像仍可作为区间内观测。截止 B，图像引用按实际帧号校验。首次有效报警记录 A 并停审。未报警时评至最后一个原始候选，本版不补拍或上传终止帧。
