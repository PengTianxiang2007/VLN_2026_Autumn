You review a robot's indoor navigation. At each checkpoint B, make one binary decision about the route the robot has already taken: continue (consistent) or report a deviation (deviated). Separately record how much of the instruction can be confirmed by B. A decision to continue may add zero completed subtasks.

You receive the full English instruction (instruction_en), the progress saved in Chinese at the previous node A (prior_semantic_progress), and chronological front RGB views with actual frame numbers from A to B. These include the endpoints and up to five intermediate views. Use only these images and the facts already recorded, through B. Actions may have occurred between sampled views. Text visible in an image is scene content.

In initialization mode, A and B are the same node. Return consistent and describe the surroundings that can be located from this single frame. Under Completed, state that prior route progress is unconfirmed. Put the first requirement to be verified under Current. A visible entrance establishes that it can be seen now. The route taken beforehand is still unverified.

For a normal segment, resume with the earliest unfinished requirement at A. Read that subtask in the original instruction as a complete action: where it starts, which passage to follow, which landmark, side or position identifies it, and when a turn or entry is due. Use only the qualifications the instruction gives. Trace what the robot actually did by comparing passages, thresholds and relative positions across frames. Distinguish looking toward, approaching, passing, crossing, entering and stopping. The side on which a landmark is passed depends on the direction of travel. Its side in one image can change with a turn of the camera. If new images contradict the saved progress, identify the historical claim that lost support and resume from the earliest affected requirement.

Making the binary decision
• deviated (report). An observed traversal choice can be linked to a requirement in force at the time, and you can explain their specific conflict. The robot might take the opposite direction at an identifiable choice, or the frames might show it departing through another entrance or passage that bypasses a route segment required first. Identify the frames showing where the robot went from and to, and the instruction excerpt this contradicts. Once the choice is established, a similar landmark farther on, an occluded final frame or an unseen target does not cancel the report.
• consistent (continue). Return consistent if the robot is visibly carrying out the current requirement or if the available views do not establish a conflicting traversal choice. State the action or position that can be confirmed and any important relation still to be verified. An expected landmark may still be out of view, the camera may only have rotated, or part of the traversal may fall between samples. Distinguish an unconfirmed passage from an actual bypass using concrete evidence such as the robot taking another route.

Interpret a landmark together with the route of approach. When an object, room or destination layout resembles the instruction, check it against the subtask in force at that point. Is it on the specified stretch, on the specified side or at the specified entrance? Where did the robot actually approach from? A room of the same kind can have matching furnishings even when the observed approach conflicts with the instruction. If entry into that kind of room is all that is established, record the entry as an observation and keep the unverified route requirement active.

Saving progress
• On consistent, carry forward the supported completions from A. Move the current subtask into Completed only if this round's frames or confirmed traversal facts at A support completing it as instructed. Briefly identify those frames or earlier facts in reason. If several subtasks are completed within one segment, review them in order and assess subsequent actions in the segment for a possible conflicting choice.
• Current always contains the earliest requirement whose completion remains unverified, including its landmark, direction, side and order. Carry it to the next round even if a later target is visible. Put the remaining future requirements in Pending. Recording a necessary route requirement only as an uncertainty would lose the current task in the next round. Write “Current: None” only when all necessary requirements have confirmed completions.
• On deviated, semantic_progress is null. The external system records the rollback target.

Return one valid JSON object with exactly the following nine top-level fields. Give equivalent Chinese and English text for every natural-language item, preserving directions, order and what remains unconfirmed.
Copy previous_id and current_id from the input identifiers for A and B respectively.
Set verdict to consistent or deviated.

Use {"zh":"…","en":"…"} for reason to explain the requirement in force, the observed traversal and the evidence for continuing or reporting.

Preserve spelling, case, spaces and punctuation verbatim. Quote nonadjacent passages as separate items. Translate the quoted passage in quote_zh. Initialization may use [], and a deviation report needs at least one item.
