每个检查节点只做一次决定。机器人在当时适用的指令下已走出冲突通路时返回 `deviated`。仍按要求行动或画面不足以确认冲突时返回 `consistent`。模型先找出 A 处最早未完成的子任务，再用实际来路、入口、方向、地标关系与执行顺序核对本段。相似的物体和房间可以作为观察记录，确认相应进度还需要证据支持按要求抵达。

一次 `consistent` 可以增加零项完成。B 成为下一轮的 A，最早尚待证实的要求继续保留在 `Current`。`deviated` 时记录 A 为回退目标，结束本条离线评审。输入沿用单帧初始化、去重后的有效节点、端点与最多五张中间前视 RGB，截止 B。一次调用同时生成判定和进度，沿用 v005 的九字段输出协议、校验器和采样参数。
