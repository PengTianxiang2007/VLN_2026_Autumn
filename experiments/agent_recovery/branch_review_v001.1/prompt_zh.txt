你正在审阅机器人在一个回退节点 C 处的路线选择。请在一次调用中完成两个任务：识别 C 处直接可选的支路，并根据后续时序观测识别机器人此前实际选择并走入了哪条。

【固定七图输入】

1. C_left70：节点 C 的左侧 +70° 图像。
2. C_front：节点 C 的正前方 0° 图像。
3. C_right70：节点 C 的右侧 −70° 图像。
4. C_plus2：C+2 step 的实际前视观测。
5. C_plus5：C+5 step 的实际前视观测。
6. C_plus8：C+8 step 的实际前视观测。
7. C_plus10：C+10 step 的实际前视观测。

前三张来自同一节点位置和姿态下的不同观察方向，不表示机器人执行了转向或移动。后四张按时间顺序记录已经发生的行动，采样间隔不等，使用机器人在各 step 当时的真实前视朝向。所有支路方向统一相对于 C_front 的 0° 朝向描述，不能直接使用侧视图或后续图像自身的左右方向。

【什么算当前支路】

支路是机器人在当前同一处决策位置可以直接选择的不同通路。它必须对应当前的一项选择，不能是建立在先前某项选择之上的后续选择。

例如：当前可以向前进入走廊，走廊更远处才分出左右两个房间，则当前记录“向前进入走廊”这一条支路，不能把远处两个房间列成当前两条支路。如果当前同一处就有前方通路、左侧入口和右侧入口，分别形成直接可选的通路，则可以记录为三条支路。

“直接选择”不要求原地转向。为进入眼前入口所需的短距离靠近仍可属于同一次选择；但必须先选定并沿另一条通路行走、之后再作选择才能进入的入口，属于后续分叉。

一处入口及其后方空间是一条支路。同一入口出现在多张图中也只记录一次。不同方向词或不同房间名称本身不能证明存在不同支路。绕过家具两侧后仍汇入同一空间，不因此构成两条独立通路选择。

【任务一：逐视图盘点、跨图匹配、形成清单】

先只看 C 处三张图。分别在 C_left70、C_front、C_right70 中寻找候选入口，包括近处门洞、侧向通道和可以直接离开的连续地面。每图独立列举，同一入口出现在不同图中时先各自登记。候选不等于已确认支路。每个候选用一个本图编号（左图 L1…、正前图 F1…、右图 R1…），并简述它在画面中的位置、可见的入口轮廓或地面以及附近固定地标。某图没有候选就填空数组。一图可有多个候选。

再将三图中的候选对应到实际入口。依据共享的墙角、隔断、门框、地面连接和地标的相对位置，说明哪些候选看见的是同一个入口、哪些应分开。只在有同一入口的具体证据时合并；相近的颜色、相似的房间外观或相同方向不足以认定重复。只在一个视图可见的入口也可以独立成立。对仍存疑的对应关系在 uncertainties 记录局限。

每个候选恰好进入一个 candidate_groups 分组，单个候选也单独成组。每组记录 candidate_ids、处理依据 reason 和最终 branch_id。满足当前直接选择条件的组一组对应一条 B 支路；如果是封闭面、后续分叉或证据不足以确认为当前直接通路，branch_id 填 null 并说明依据。不要凑数量或猜测遮挡后的目的地。

最后根据保留的组形成完整 branches 清单，方向统一以 C_front 为准。后四张图用于随后匹配实际行进路线；某个当前入口没有在后四张出现，本身不构成排除理由。

【任务二：识别此前实际选择的支路】

将 C_plus2、C_plus5、C_plus8、C_plus10 与当前支路清单对应，判断机器人从 C 处离开时实际选择并走入了哪条。

结合入口是否被穿过、通路是否连续、固定地标相对相机的位置变化等证据。区分看向入口与进入入口、原地转头与转入通路、房间变得清楚与实际进入房间、靠近入口与已经沿该支路离开。不要把为进入眼前入口做的必要靠近误判为先选了另一条支路。

识别的是 C 处发生的这次选择。后来在更远处选择的路线不能替代 C 处的支路编号。若图像只显示转头、短距离调整或采样不足以确定实际支路，返回 uncertain，不强行匹配。

上游流程已将该次尝试判为需要纠正。本调用负责识别实际走过的支路，这个触发背景本身不是某个支路 ID 的证据。不要猜测原任务、重新选择正确路线或生成恢复指令。

【输出格式】

只输出 JSON，顶层字段恰为 view_candidates、candidate_groups、branches、previous_attempt、uncertainties。自然语言使用中文。

逐图候选在 view_candidates 的 C_left70、C_front、C_right70 三项中输出，每个候选含 id 和 description；跨图处理写入 candidate_groups。

branches 是数组，允许为空。每项恰含：
- id：B1、B2……，唯一且连续。
- direction：front、front_left、left、front_right、right、back、unknown 之一，相对于 C_front；back 也必须有图像证据。
- entrance_description：辨认入口或通路的局部视觉特征。
- current_choice_basis：为什么这是当前直接选择，而不是选定另一条通路后的后续分叉。
- evidence_image_ids：支持本项的图像 ID 数组。

previous_attempt 恰含：
- status：identified 或 uncertain。
- branch_id：identified 时必须引用本次 branches 中的 ID；uncertain 时必须为 null。
- evidence_image_ids：支持匹配或说明证据局限的图像 ID 数组；identified 时不能为空。
- reason：实际通行如何对应该支路，或为什么无法确认。

uncertainties 是中文字符串数组，无额外疑点时为空。所有证据 ID 只能引用上述七张输入图像，不增造图像、支路或时间点。
