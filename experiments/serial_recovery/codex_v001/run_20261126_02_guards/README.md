日期：2026-11-26 UTC。状态：实现与 CPU 故障注入验证完成；没有启动导航实验。

## 目的、版本与协议

用户要求补上 JEV/Codex 阻塞保护，并随后把最多 3 次请求改为 10 次。此版保持串行在线算法、英文恢复提示词和 180 步预算不变；只补有限重试、累计期限、接管无进展检测及技术中断传播。

`DEFAULTS.version=codex_serial_v001_guard1`。JEV 单次 120 秒、最多 10 次、累计 420 秒；Codex 评审单次 300 秒、最多 10 次、累计 600 秒；次数均含首次请求，累计预算先达到时提前停止。退避最多 60 秒。父进程独立对一个动作边界设置 1800 秒期限，使用非阻塞分段读管道，半行回复不能绕过超时。GPT 接管设置 300 秒无成功工具调用、600 秒无移动动作、2700 秒总期限。

鉴权等永久错误立即退出；技术中断停止队列并写 halt.json，不计导航失败，不执行默认 STOP，不重放未知是否已完成的动作。若发生原生物理终止或正常耗尽 180 步，仍沿用原导航评分规则。保护只应用于新在线流程；历史离线评审的默认重试行为没有改动。

源码基于当前实际 HEAD 与工作区，输出目录保存 Git SHA、相关差异、源码快照和文件 SHA256。主要代码：`core/codex_serial_guard.py`、serial review/runtime、live takeover、worker、原生 launcher；共享 Codex 客户端只额外记录进程出生 tick，机器人桥补成功调用计数及执行前期限复核。
