# 原十条 Crossing 的360°离线画面补采

更新时间：2026-11-06。状态：初始化期间主动停止，未产出画面。

## 目的与范围

仅补充外部 Agent 所需的周围观察。原固定十条、八场景、九个唯一 Crossing；每点8张、相隔45°，计划72张唯一RGB，十条任务共引用80张。不调用模型、不执行完整导航。

## 方法与协议

复用本仓库 Isaac Sim 4.5、VLNVerse 仿真环境及原场景 USD，新增独立相机渲染入口。相机光心的 XY 使用标定 Crossing 坐标；高度取该点对应旧判断帧的机器人根部 Z 均值，加 H1 原相机静态高度偏移0.72m。每点固定光心，仅改变 yaw；0°为场景世界坐标+X，向+Y逆时针递增，不表示机器人原来的前方。俯视15°、水平视场90°来自 H1 原相机资产；640×480，垂直视场按4:3像素比例设定。补采采用原任务同类 distant/disk 灯光，定位到当前采集点。

旧轨迹未保存相机朝向和完整物理状态，因此这是标定点的新增静态观察，不是旧判断帧的像素级恢复。原判断帧位置与标定点相差约0.03–0.95m；每条差值写入清单。没有机器人实体、动态运动或策略记忆；不使用 Oracle 正确路线/朝向来选择取景方向。标注源中 `pending_user_review` 与几何来源保留，不将其升级为独立人工真值。

原轨迹 seed=2；渲染固定 seed=20261106。旧到达前/走错后RGB及动作只作后续配准依据，并保留原SHA256。原始图片不添加箭头、正确路线或支路答案。

Git及未提交差异、使用的源码和相机资产参数，在输出目录 `source/`、`provenance.json` 冻结；历史运行不覆盖。只使用重新核验空闲的GPU，结束/异常时清理本次进程。

## 启动方式

仓库根目录：

```bash
python3 scripts/prepare_crossing_panorama.py --output outputs/agent_route_choice/v002/capture_20261106_01
python3 scripts/run_crossing_panorama.py --output outputs/agent_route_choice/v002/capture_20261106_01 --gpu 0
```

GPU0仅为本次已核验候选，入口会再次检查全部GPU和目标卡的归属、空闲状况。每个场景单独启动仿真子进程，限时1800秒；自动保存元数据与退出清理证据。
