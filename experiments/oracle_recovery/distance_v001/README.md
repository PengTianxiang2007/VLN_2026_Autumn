## 目的与授权

在原人工集的33条独立任务、34个错误选择事件上进行新的 StreamVLN / VLNVerse H1 physical 导航。
用户要求以到完整正确参考折线的最短水平距离识别偏航，达到阈值后自动纠正，无在线 GPT 审阅。
用户随后要求代码完成后启动 GPU 仿真，核验正常后由后台队列推进，不持续人工跟踪。历史 Oracle 结果不覆盖。

## 预定协议

seed=2，保留原生提示词、动作队列、STOP/跌倒/卡住与25000物理tick预算。
正确路线瞬移组保留干预时的 policy memory，允许重复纠正；另提供实际存档回退组，沿用恢复存档记忆/预算、一次回退后自主续走的协议。
默认偏移阈值为0.75、1.5、3、4米，依次称early/short/medium/long；这些是距离条件，不再是旧语义阶段。
四组独立仿真运行，不声称共享前缀。具体源码、样本和配置由准备工具冻结到新输出目录。

选择依据：同34事件历史轨迹中，标注点前最大偏移0.656米；标注后达到四档的事件数分别34/32/23/16。
这些统计用于协议设计，不是独立评测或新仿真成绩。阈值可显式修改。

## 实现与验证

- `core/oracle_distance.py`：完整折线距离、落点插值、事件关联、人工集清单。
- `core/oracle_distance_runtime.py`：真实观测驱动的检测、瞬移、memory 核验及存档回退；无在线大模型审阅。
- `scripts/prepare_oracle_distance.py`：核对官方任务指令/参考路线，冻结配置、源码及原始数据哈希；只运行 CPU。
- `scripts/run_oracle_distance.py`：默认打印计划；`--execute` 才启动真实仿真，逐任务核验空闲 GPU 与主存，完成/异常清理自己启动的模型及仿真。
- `tests/test_oracle_distance.py`：12项 CPU 检查通过（含资源等待和空闲卡自动选择）。

默认落点：把人工 Crossing 点投影到正确参考折线，再沿路线前移0.75米，朝向该处后续路线。
34个落点距原标注点最大1.260米，均未因路线长度不足而截断；6个落点在原生3米成功半径内，单独记录，不剔除样本。
落点的真实物理稳定性仍须 GPU 验证，CPU 几何检查不等于碰撞/可行走验证。

偏移首次达到最小阈值时，以最近一次低于该阈值的位置关联最近的人工错误 Crossing；同一次持续偏移固定该事件及落点。
达到当前组阈值且模型动作队列为空时才纠正；若等待队列期间回到阈值内，不执行过期纠正。
这只是固定的距离判据，不判断语义正确性，也不依据历史帧号触发。返回参考路线后可重新触发，不限制瞬移组纠正次数。
分叉附近的多条参考线/回环可能使最近距离低估错误，日志保留原始距离及事件归属。

checkpoint组在本次仿真距离标注点不超过1米、距离参考线小于最小阈值且队列为空时保存实际状态；每个事件仅保存首次合格状态。
发生阈值偏移但无对应实存状态时记录未触发原因，不伪造旧录像存档。沿用旧实验每条任务最多一次回退；双事件任务保留两个事件ID，未触发事件如实统计。
回退使用已有policy/RNG/预算恢复与50tick稳定代码，不声称完整PhysX隐藏状态位级恢复。

## 命令

从仓库根目录执行。准备命令拒绝覆盖目标；更改阈值应建立新运行目录。

```bash
python3 -B scripts/prepare_oracle_distance.py --output outputs/oracle_crossing/distance_v001/run_20261115_01
python3 -B scripts/run_oracle_distance.py --campaign outputs/oracle_crossing/distance_v001/run_20261115_01
# 只有本条启动仿真；GPU编号必须经过实际资源检查。
python3 -u -B scripts/run_oracle_distance.py --campaign outputs/oracle_crossing/distance_v001/run_20261115_01 --gpu 2 --sim-gpu 3 --execute
```

可用 `--arms early` 或 `--episodes <episode_id>` 选择冻结清单的子集；未提供时运行全部五组。
准备时 `--thresholds 0.75 1.5 3 4` 可覆盖默认值，checkpoint沿用第一档。
已核验完成的任务按哈希跳过；失败/中断目录拒绝自动重试，保留证据另行诊断。
