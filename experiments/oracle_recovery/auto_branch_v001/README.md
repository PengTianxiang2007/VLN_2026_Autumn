## 方法

输入只有官方正确参考折线与本次已实际观察到的机器人位置序列，不读取人工分叉标注或历史错误帧。沿实际行走距离记录轨迹，过滤3厘米以内的原地位置抖动；参考路线对应点限制在上次匹配弧长±(本步位移×1.5+0.1米)内，等距时优先接近上次进度，减少回环/近平行路段的跳跃匹配。

偏离完整参考折线的最短XY距离达到0.75米时，回看最近8米已走轨迹，按5厘米等距重采样，拟合“此前小幅偏移稳定、之后距离持续增加”的单变化点模型：`d(s)=b+k*max(0,s-s_branch)`。稳定偏移`b`限制在0–0.35米，分离斜率`k`在0.05–1.25；需要至少3个真实运动观测、0.5米跨度、0.3米分离后缀、此前有0.35米内的路线对应、拟合RMSE不超过0.12米。由最小误差的变化点及相邻真实观测的连续路线进度，得到参考路线上的估计分支锚点。

锚点在本次偏离中固定，不随错误路线上的后续运动漂移。等模型动作队列为空且当前仍超过0.75米，再从该锚点沿正确路线前移1.25米，朝向落点处路线前进方向。低于触发阈值时不纠正；回到完整参考路线0.35米内后结束本次偏离。若绕行接入另一段路线，显式记录对应关系重定位并重建轨迹段，避免下一次偏离沿用旧锚点。瞬移后同样重建轨迹段，以实际稳定姿态和已知落点弧长初始化，禁止把瞬移跳跃当作真实行走。

无法确定分支位置时记录具体原因并继续原模型，不回退到“当前位置投影”。位置/朝向稳定、记忆保留、重复纠正、原物理预算和停止规则沿用原实现。超过参考路线终点时截断；近目标落点单独记录，不改变原生评分。

这是轨迹几何的分离位置估计，不是场景拓扑分叉的精确识别。急弯、缓慢漂移、多次偏航叠加、回环、路线本身不贴近实际可走轨迹和楼层重叠可能导致不确定或误定位；估计及残差/区间必须保留。仍使用正确参考路线，属于Oracle。
