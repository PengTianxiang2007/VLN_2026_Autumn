A recovery checkpoint is a location where the robot can choose between multiple branches leading to different spatial areas, either now or within the next few navigation steps.

If reaching a visible branch first requires choosing and following another branch, it is a downstream branch. Do not count it as an additional independent option at the current local decision. When the robot later reaches that downstream decision location, its branches may define a new recovery checkpoint.

Identify the branches that can be selected now or within the next few steps. Explain the evidence supporting them. If a visible opening is excluded because it depends on an earlier branch choice, explain that dependency.
