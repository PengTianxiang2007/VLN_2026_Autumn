操作说明与保存方式

普通 Crossing 是轨迹中的路口；错误选择 Crossing 同时属于 Crossing。同一帧重复点击会更新类型，不会重复增加点。点击地图点或列表中的帧号可选中；每一行都有删除按钮，也可删除选中点。撤销删除仅对本次打开页面的操作有效。

标注绑定当前画面及其真实位置。地图可拖动或使用 ＋ / − 放大缩小。完整实际路线浅色显示，走到当前帧的部分加深。原始档案没有逐帧朝向；地图不绘制推测朝向。标为“沿用上一观测”的帧不能标注。

快捷键：← → 逐帧，空格 播放/暂停，C Crossing，E 错误选择，Delete 删除选中点，Ctrl / ⌘ + Z 撤销删除，Ctrl / ⌘ + S 保存 HTML。

请使用右上角“保存标注后的 HTML”下载文件。新文件包含全部画面、地图和标注，重新打开可继续标注；标完后将这个新文件上传服务器。浏览器自动暂存用于防止误关，但不会修改原文件。没有标注点的任务，也可以勾选“本条已标注完成”。时间是录像回放时间，不是物理仿真时长。
