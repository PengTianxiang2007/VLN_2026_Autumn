如何读这张地图

S 起点 / G 目标 / E 终点S 是本次实际起始位置；G 是参考路线目标；E 是本次实际终止位置，不代表一定成功。
C 分岔路口来自此前的地图标定。它表示相关决策区域，不是必须经过的精确触发线。
D≈ 偏离段回看起点有明确观察区间时依据原审阅记录；否则按本段轨迹接近相关 crossing 的位置回溯估计。不是逐帧错误真值。
P → T 瞬移P、T 是记录中的精确瞬移前后位置。紫色虚线是位置跳变，不是机器人走过的路线；箭头表示方向。

播放与时间轴：每一步对应已有导航观测，瞬移处单独插入“前 / 后”两个节点。机器人会直接从 P 跳到 T，绝不沿紫线模拟行走。1× 为每秒 4 个记录节点，并非真实物理时间；动作编号从 0 开始。

分岔与红色段：有纠正时，红色表示该次审阅关联的偏离回看区间。D≈ 只用于帮助定位，请结合同步画面和原始审阅理由判断实际错误起点。没有纠正的运行中，红色仅提示距参考线 ≥0.5 米的几何偏离（至少连续三条记录才启用），不自动认定语义走错。

朝向与观测：当前位置箭头使用记录的机器人朝向；瞬移后显示记录的实际新朝向。终止节点没有独立朝向时不画朝向箭头，画面明确标注复用末次观测。

操作：点击右侧“偏离段 / 瞬移前 / 瞬移后”可精确定位。滚轮缩放、拖动平移；“接管局部”放大相关路口，“全路线”找回起点与目标。点击画面可放大。灰色对照路线来自另一独立运行，不与当前时间轴同步。
